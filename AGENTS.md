# Project structure

- Preserve vm-ir-analysis-v1 and frozen offline histories; Hardened VM v4.3 uses production-owned FunctionIR and is the Level 3 default for Luau/Roblox, while the legacy backend remains available only through the explicit emergency rollback variables documented in README.md. V4.3 binds constant descriptors to the ordered regional rolling state, caches repeated constants inside a region, permutes frame slots per prototype and checks decoded capsule content; describe these as effort-increasing and corruption-detecting measures, never as secrecy or Luraph parity. Keep Studio compatibility and artifact-only resistance reported separately from local functional evidence.

- Keep adversarial-v1 as an offline versioned harness with binding-aware normalization, explicit unsupported stages and hash-pinned historical adapters; never import it into production, because incomplete extraction must not be reported as target resistance.
- Keep adversarial-v2 independent and offline with stage-censored common IR, provenance and pre-scoring persistence; preserve the predecessor and production hashes, because fair comparison must not equate adapter coverage with target resistance.
- Preserve adversarial-v2-snapshot-20261026 as read-only hash-verified original bytes; delivery corrections and memory diagnostics live in adversarial-v2-correction, because new evidence must never retroactively replace failed runs or analyzer pins.

- Keep polymorphic-vm-v3 behind an explicit offline-only entry point in benchmarks/polymorphic-vm-v3, consuming shared compiler IR without production imports; local page decoders and informed artifact-only recovery must be evaluated together before any promotion.

- Keep real string-region specialization in benchmarks/string-regions-v1 only, with logical instruction checkpoints inside fused regions and artifact-only recovery scored afterward; no production imports or promotion, because direct partial evaluation restores its literals.
- String-region score consumers require an explicit file/hash selection per artifact and mode and reject ambiguity; historical recognizer provenance is labeled unrecorded rather than inferred, because reindexing cannot establish unlogged run identities.

- Profile reads are owner-scoped through database RLS using auth.uid() = user_id; enforce account privacy server-side, not only in the interface.

- Relational recovery formulation evidence lives in benchmarks/audit-vm-relational-triage-v1; require a causal model gate before any executable experiment, because an inverse coordinate projection can defeat the proposed obstacle without modifying production.

- String inverse permutations use the pure minimum-width Base85 codec with an artifact-local decoder and no new RNG/name draws; preserve constant restoration order because transport efficiency is not protection.
- Final builtin directories use a pure packed byte transport, fixed position alphabets use decimal-byte presentation, and complex dispatch leaves select one per-iteration handler before a shared call; preserve RNG draws, inline operations and PC/yield semantics because these are emission changes, not demonstrated resistance.

- Structural emission uses one exact-position prototype/capture directory, ordered live identity units and binding-proven pure numeric-table cleanup after legacy RNG draws; preserve E_PROTO, verification scheduling and the instruction cache because emission cleanup is not demonstrated protection.

- Subdirectories have their own AGENTS.md; read applicable files before edits, especially src/lib/obfuscator/AGENTS.md for engine work and benchmarks/AGENTS.md for audits.
- Generation shares one session, rejects external reentry and isolates observers from RNG/token caches. Large jobs reuse deeply frozen tokens by exact source/mode in a session cache bounded by keys, token count and logical content; parsing copies mutable AST metadata and entries clear on success/error; never cache mutable ASTs or persist source.
- Keep the obfuscation screen, gate, CLI and tests; the public Cloud obfuscation API was removed by request.
- Browser and CLI share the engine; offline Luau tests cannot guarantee Roblox Studio behavior.
- Browser generation uses a typed module worker and optional lifecycle events from the shared engine; serialize it with an origin-wide Web Lock because generation state and local-history reconciliation must not race across tabs. Explicit cancellation and validation retries terminate the browser worker, settle the session with an error and save only interrupted/failed metadata before releasing the lock; the CLI engine remains unchanged.
- Store only job metadata (including effective seed, normalized generation options and engine version) and exact generated artifacts in IndexedDB, never original source or credentials; keep persistence failure independent from generation success so downloads remain available.
- Final runtime renaming uses lexical binding conflicts and re-resolves emitted use identities; decimal presentation runs structurally after legacy RNG draws, because reuse and numeric spelling must not shift payload randomness or capture bindings. Internal legacy presentation switches retain byte reproduction; private register fields and word/position codecs remain structural/data-only.
- Runtime helper distribution lifts selected real functions into the outer table and passes immutable captured references explicitly at existing direct call sites, rejecting rebinding or escaping helpers, because per-invocation registers, upvalues, policy state and multireturn/yield protocols must remain unchanged.
- Prototype metadata uses one independently transported exact-position directory with immutable false markers for uncaptured prototypes; native identity units retain ordered live short-circuit reads, and numeric-table cleanup requires binding-proven absence of uses and finite literal arithmetic, because emission cleanup must not weaken validation or erase effects.
- There is no dashboard: the workspace header contains only the top-right Logout hamburger; the workspace removes the root `.light` class without deleting saved preferences, so its fixed dark presentation does not change login or authentication logic.
- Source input and persisted configuration belong in the fixed-height inline composer; attachments retain an explicit in-memory input kind and separate raw content so file cards never populate the editor, while level and functionality menus stay separate.
- Level selection uses a reusable controlled Radix Popover/Slider with three discrete values, fixed full-track star coordinates revealed by the range clip, and an optional reset default; the composer owns persistence and job options so presentation never changes generation logic.
- Present obfuscation as a single in-memory session conversation, not an AI service: snapshot each accepted submission and its exact output independently so later jobs cannot overwrite earlier downloads; artifact naming is a pure presentation helper that never renames history artifacts or changes output bytes.
- Keep reference-specific SVG icons in a shared presentation module; the exchange view opens exact output only on demand in an accessible Radix dialog with CSS-only wrapping and reduced-motion-aware transitions, keeping large artifacts out of the transcript layout and preserving artifact bytes.
- Attachment selection uses a text MIME hint plus supported source extensions and rejects media MIME types and binary control content before accepting source, because picker filters alone are not validation.
- Keep presentation in global/scoped semantic CSS tokens and an inert full-viewport workspace wrapper: the transcript scrolls behind floating header/composer controls, with ResizeObserver-measured end padding so the latest result remains reachable; never modify auth or generation logic for styling. Landscape CDN pointers retain provenance; public landscape fallbacks are required because asset proxy paths return HTML on bare localhost.
- Greeting periods are a pure presentation helper using the visitor's local clock, refreshed while the page remains open, so time rules can be tested independently of generation.
- The session view is a local code-processing interface, not AI chat: retain its code editor and exact-artifact previews rather than Markdown/AI transport primitives; viewport-only styling changes must not replace these controls or alter artifact bytes.
- Obfuscation options use the original label/description layout with a square rounded-corner checkbox (filled circle inside when on, empty when off) backed by the `--control` surface token; never switch back to a sliding pill switch.
- Keep source-emission dialect choices separate from runnable VM platforms so the site cannot promise unavailable backends.
- Constant transport carries a local checksum verifier emitted before constant restoration and failing with a controlled error; it detects corruption and edits that do not update it, never authenticity against someone who controls the artifact, so do not describe it as anti-tamper.
- Keep historical audit evidence immutable and release variants self-contained. Use audit-iy7-confirmation for preregistered balanced timing and audit-iy7-localized for scratch-only RNG-order, controlled-GC and pure-decoder diagnostics; unresolved bounds prevent promotion, because packaging and diagnostic changes must not silently replace production.
- Keep the KB fused-key experiment in benchmarks/audit-kb-fused-v1 with hash-verified scratch engine variants and an explicit offline entry point, because experimental instruction semantics and noise ablations must not alter browser/CLI production artifacts or session protocols.
- Keep contextual feasibility models and preregistered adversarial normalization in benchmarks/audit-vm-context-v1, with maintenance analyzer revisions beside frozen predecessors; resolve the standalone model before any scratch engine change, because finite-context normalization can reject the hypothesis without risking production.

- Keep adversarial-v3-real as an offline, static-only layer that never edits v1/v2/v3: fixes are new revision files, the independent VM route imports only neutral frontend code, and every command runs through the logged runner, because evidence must stay reproducible and comparisons must not rewrite earlier results.
- Keep artifact-only-v1 offline and artifact-only: evaluate only hash-listed locally generated artifacts in a bounded sandbox and keep unknown artifacts static-only; frozen files never change. The authorized executable v4 remains private and unpromoted until functional, consumer, invariance, causal and Studio gates pass; minimal pin/scoring/censoring wrappers live beside campaign evidence rather than changing frozen recovery capabilities.
