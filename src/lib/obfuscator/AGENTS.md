# Obfuscator rules

- Hardened v4.3 is the Level 3 executor for Luau/Roblox, using production-owned FunctionIR, ordered region-bound capsules, regional register banks and eligible fusions. Preserve descriptor indirection through the current rolling state, per-prototype frame-slot permutations, regional repeated-constant caches and decoded-content tags. These mechanisms increase extraction work and detect accidental/direct edits; they are not authentication or cryptographic secrecy. Preserve the explicit legacy rollback path and reject unsupported targets/execution modes rather than silently falling back. Offline campaign tooling must never be imported by the production engine.
- V4's rolling consistency state and local encodings are not authentication or path-dependent secrecy; functional tests, hook failures, artifact recovery and Studio behavior remain separate measurements and must be reported as such.

- Artificial yields are default-deny and require explicit entry-coroutine authorization; protected invocation boundaries clean up elapsed timing on reentry/errors without wrapping every CALL, because coroutine protocols must not change silently.
- Keep VM accounting in execution-policy.ts: per-coroutine shared `remaining` decremented per instruction and sampled elapsed processing intervals, not exact CPU; known task.wait uses pause/resume, clears spent only on normal return reporting positive scheduler elapsed, and preserves remaining/checks; unknown functions and failed waits are conservatively timed.
- Proto cache (`_protoCache`) stores decoded instructions with pre-resolved opcodes (field [5]) per prototype position; trade-off: heap-resident decoded bytecode facilitates dynamic analysis but eliminates 3 XOR + 2 MUL + 2 MOD per dispatched instruction. Only immutable data is cached; registers, PC, upvalues and execution state are per-invocation.
- Inline opcodes (MOVE, LOADK, arithmetic, comparisons, jumps, table ops) are emitted directly into dispatch tree leaves, eliminating function-call overhead; complex opcodes (CALL, CLOSURE, RETURN, etc.) still use the dispatch helper. Inlined opcodes skip handler fragmentation.
- Instruction limits are diagnostic-only and opt-in per invocation, never coupled to intenseVm or emitted in production, because legitimate long functions must not be truncated.
- Emit executable handlers only for used non-inline operations plus CLOSURE; inline leaves remain dispatch entries without redundant functions. Shared handlers/cache live with the VM instance, because escaped closures may call them later.
- Production uses the measured single dispatch tree; partitionedDispatch is an explicit experiment, because extra modulo/bucket routing must justify its cost.
- VM handlers cache encoded native references once, hoist dispatch helpers per invocation, specialize fixed calls, and proxy only captured registers; preserve call counts, nil/false, coroutine yields, and shared upvalues. The CALL handler separates wait detection (by reference identity via `policy.waitRef`) from arity specialization (0-3 args).
- No `\xHH` hex escapes in any layer of generated output; use 3-digit decimal `\NNN` escapes only. The `\u{...}` escape is also forbidden because it produces multi-byte UTF-8 for values > 127.
- Direct execution is the default: emit VM and native factories as code and compress only encoded program data; source-compiling loaders/packers require explicit dynamic mode, because normal LocalScripts cannot compile source.
- Compressed loaders and generated VM builtin lookups resolve the current script environment rather than assuming shared `_G` contains globals; preserve the compiled chunk environment and user `_G` semantics, and escape payload literals to avoid delimiter collisions.
- Each local declaration owns a distinct slot tracked separately from scope name restoration; emit CLOSE for exiting binding lifetimes on normal and jump paths, because slot classification cannot represent successive captured cells.
- Patch `continue` targets after emitting each loop tail, because numeric-for and repeat must jump to increment/condition rather than the body.
- Apply Roblox probes only to Roblox output; avoid process-crashing traps and global metatable changes.
- Constants retain two XOR layers and masked numbers; word transport selects complete decoder cost. Builtin keys are private per-context data with one explicit string.char bootstrap; live anti-hook reads must not become cached-value comparisons, because client encoding is not secrecy.
- Anti-hook verifies identity, capture-time stability and functional contracts, never tostring appearance alone. Fail with controlled E_HOOK/E_INTEGRITY/E_PROTO errors rather than empty success; no destructive traps. Pre-capture substitution remains a limitation. Optional bit32 uses `or {}`; LZW rejects invalid codes.
- Prototype metadata independently transports exact positions and capture lists in one directory; immutable false marks no captures, nil rejects invalid positions with E_PROTO before header access; execution cells are never shared. String decoders share the immutable inverse alphabet and keep 128-byte blocks; CONCAT uses native right-associated operations, not tostring coercion.
- GC Fixes releases consumed cipher blocks after caching strings; bounded fragment assembly preserves exact bytes. Retired toggle fields are removed by normalize-toggles at generation and history-write boundaries; final emission stays compact without soft breaks, because physical one-line presentation is not host metadata stripping.
- Source emission uses the existing AST through unparser/ with exhaustive visitors and a token writer; keep diagnostic regeneration explicit so production never embeds source dumps.
- Luau interpolation is lexed with nested brace/string boundaries and lowered into existing AST literal-format method calls with single-result holes, matching official Luau `%*` conversion without global tostring lookups.
- Native/VM crossings use binding-identity region analysis: box only cross-region native bindings, retain ordinary locals and explicit native-to-native closures, and keep unmarked children VM; never copy captured values, because writes and closure lifetimes must agree.
- Diagnostic VM emission is opt-in through the explicit diagnostic entry point, with a private chunk argument; production options never enable counters or publish internal references.
- Builtin hiding resolves expression bindings and edits only unresolved global spans; declarations, native locals/parameters, methods and literal bytes must never be rewritten by spelling.
- Generation seeds cover synchronous random choices with finally-scoped name/emitter restoration; callbacks suspend generation RNG, report failures through callbackErrors, and cannot start an external generation while an internal session is active. Direct VM audit failure aborts explicitly because its return type has no report channel.
- Numeric-for validates initial/limit/step once in native order, enters the first iteration without subtract/add cancellation, and keeps its visible index separate from the internal counter.
- Elide CLOSE only for slots provably uncaptured by all children; remap absolute jumps and retain skip-next positions, because captured lifetime boundaries and native bridge cells must remain intact.
